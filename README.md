# Yova TV

La télé du monde entier, dans le navigateur : plus de 11 000 chaînes gratuites en direct
(liste publique [iptv-org](https://github.com/iptv-org/iptv)), un espace Monde arabe, un Espace Enfants
avec YouTube Enfants intégré, et des raccourcis vers vos applis (YouTube, Netflix, Disney+…).

**Ouvrir Yova TV :** https://mpowercanada.github.io/yova-tv/

- Smart TV Samsung / LG : ouvrez le navigateur internet de la télé et tapez l'adresse ci-dessus.
- Android TV / Google TV / Fire TV : installez l'appli [Yova-TV.apk](https://mpowercanada.github.io/yova-tv/Yova-TV.apk)
  (sur Fire TV, avec l'appli « Downloader »).
- Télécommande : flèches pour naviguer, OK pour regarder, Retour pour revenir.

Yova TV n'héberge aucune vidéo : il lit des flux publics et gratuits diffusés par les chaînes elles-mêmes.
